# Simulated currency changes on a live chart

A Python project with Matplotlib about simulated imaginary currency price changes on a LIVE chart.

## What does this project do?

- Shows imaginary currency price changes per second
- Randomly changes the prices
- Shows the prices in the code editor terminal

## Technologies

- Python
- Matplotlib
